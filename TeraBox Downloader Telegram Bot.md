## ⚙️ How It Works

<div align="center">

| Layer | Responsibility | Tech |
|:---|:---|:---|
| 🤖 **Telegram API** | Receives links, sends progress updates, uploads files | `python-telegram-bot` |
| 🔍 **Link Parser** | Extracts the internal TeraBox file ID and tokens | `BeautifulSoup` / Regex |
| 🚀 **Downloader** | Fetches the file directly from TeraBox CDN | `aiohttp` / `httpx` |
| 🎬 **Media Engine** | Splits large files and generates thumbnails | `FFmpeg` |

## ❓ Frequently Asked Questions

<details>
<summary><b>Is it really free?</b></summary>

Yes, the public bot is 100% free to use. There are no hidden fees, premium tiers, or daily download limits. If you want to host it yourself, you just pay for your own server.
</details>

<details>
<summary><b>Can I download private files?</b></summary>

No. The bot can only download files that have been publicly shared via a TeraBox share link. It cannot access your personal private cloud storage.
</details>

<details>
<summary><b>Why are large files split into multiple parts?</b></summary>

Telegram's Bot API has a hard limit of 2GB (or 50MB for some clients). To bypass this, the bot automatically splits large files using FFmpeg and sends them as multiple parts.
</details>

<details>
<summary><b>Does it support folders?</b></summary>

Currently, the bot only supports single-file downloads. Batch downloading entire folders is on the roadmap for version 5.0.
</details>

<details>
<summary><b>How do I report a broken link?</b></summary>

If a link fails to parse, use the `/help` command to contact the developer or open an issue on the GitHub repository with the failing link.
</details>
